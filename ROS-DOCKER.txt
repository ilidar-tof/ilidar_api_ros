[1] Install docker engine (https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository)
1. Set up Docker's apt repository.
$ sudo apt-get update
$ sudo apt-get install ca-certificates curl gnupg
$ sudo install -m 0755 -d /etc/apt/keyrings
$ curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
$ sudo chmod a+r /etc/apt/keyrings/docker.gpg
$ echo \
    "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
    $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
    sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
$ sudo apt-get update

2. Install the Docker packages. To install the latest version, run:
$ sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

3. Verify that the Docker Engine installation is successful by running the hello-world image.
$ sudo docker run hello-world

[4] How to run the example
1. Before run it, enable xhost x11:
$ sudo xhost +local:root

2. Copy iLiDAR ROS package to the docker image:
$ (sudo) docker cp /<PATH_TO_ORIGINAL>/ilidar_ros_cpp <CONTAINER_NAME>:/<PATH_TO_YOUR>/ilidar_ros_cpp

3. Start the docker image:
$ (sudo) docker start -i <CONTAINER_NAME>

4. Go to the folder
# cd /path/to/your/ilidar_ros_cpp

5. Build and run the package on ROS
# source /opt/ros/<YOUR_DISTRO>/setup.bash

# cd ilidar_ros
# catkin_make

# source devel/setup.bash
# roslaunch ilidar viewer.launch

6. (or) Build and run the package on ROS2 Humble/Foxy
# source /opt/ros/<YOUR_DISTRO>/setup.bash

# cd ilidar_ros2
# colcon build

# source install/setup.bash
# ros2 launch ilidar viewer.py

7. (or) Build and run the package on ROS2 Jazzy

open "/ilidar_ros2/ilidar_ros2.cpp" with the text editor. 
Find "#include <cv_bridge/cv_bridge.h>" and replace it with "#include <cv_bridge/cv_bridge.hpp>".
Save changes. Then, do it the same way as other ROS2.

# source /opt/ros/<YOUR_DISTRO>/setup.bash

# cd ilidar_ros2
# colcon build

# source install/setup.bash
# ros2 launch ilidar viewer.py

8. Exit the docker container
# exit
